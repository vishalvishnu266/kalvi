ERP Copilot — mock scenarios

Click the floating ✨ button in the bottom-right corner (or press Ctrl/Cmd + J).

Try these prompts:

  • “Open the dashboard” → server emits ui_action navigate
  • “Add a new student” → multi-step: 3 tool calls, step bar animates 1/3 → 3/3
  • “Fill the form” → server emits fill_form for any ui-form on the page
  • “Enable dark mode” → server emits set_theme
  • “Highlight” → pulses the first input
  • “Help” → renders clickable suggestion chips inside the bubble
  • Anything else → streamed echo, word-by-word
