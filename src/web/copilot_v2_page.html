Copilot — one unified surface for humans and agents

A single input handles typing, tapping, and speaking. No symbols required. Every capability — proactive suggestions, autocomplete, inline forms, confirmation, streaming, @mentions, voice, page navigation, dark mode — ships in the same <ui-copilot> element that's auto-mounted on every DSL page. Scenario walkthroughs — tap any card to fire the flow

💡 1. Proactive suggestions

The moment you open the panel, four suggestion chips are already there — tailored to the current page. No typing needed.

⌨️ 2. Live autocomplete

Start typing “attend” or “fees” — matches appear inline. Arrow keys or tap to pick. Zero LLM calls.

📝 3. Inline guided form

Some actions need details. Instead of erroring, an inline form appears — with sensible defaults and dropdowns.

⚠️ 4. Confirmation before mutations

Any action that changes data first shows a “Confirm & do it” card. Trust-building by default.

📊 5. Rich result cards

Results render as tables, stats, or text — reusing your DSL primitives inside the chat.

🔁 6. Follow-up chips

Every result offers 1–2 relevant next actions. Compounds into a workflow, not a dead end.

🎙️ 7. Voice input (stub)

Tap the mic icon in the composer to speak. Uses the browser’s Web Speech API on Chrome/Edge/Safari.

💬 8. Free-form fallback

Nothing matches? Press Enter and it goes to the “Ask the assistant” path — where a real LLM would handle it.

@ 9. Mention typeahead

Type @ in the composer — a picker of students, staff, and classes appears. Pick one to insert a chip. Say “remind Aarav about fees” to fire the tool directly.

🌊 10. Streaming multi-step (SSE)

Some actions have several sub-steps. Enrolling a student runs 4 tools — each streams a tool card and updates the progress bar live. Then the final text is typed word-by-word.

💸 11. Streaming with confirmation

Fee-charge is both mutating and streaming — you see the confirm card first, then approval kicks off the 4-step SSE flow.

⚠️ 12. Failure mid-stream

Not every task succeeds. Bulk import runs, then hits a duplicate on step 3 — the stream stops with a clear error and rollback message.

🧭 13. Page navigation

The assistant can drive the app. Ask it to open a page and it emits a ui_action navigate that Turbo-visits the URL.

🌙 14. Dark mode toggle

Ask for dark mode — a set_theme action flips <html data-theme>. Design tokens react automatically.

⭐ 15. Pinned + Recent

Every action you run is remembered in a Recent strip. Right-click any chip to pin it. Pinned + Recent survive page navigation via localStorage.

Under the hood — what powers this

Suggestions GET /agent/suggest?page=/dsl/copilot-v2 — page-aware, ~10ms, zero LLM.
Autocomplete GET /agent/complete?q=… — deterministic fuzzy match against a rules table.
Form schema GET /agent/schema?tool=… — returns fields, required flags, enum options.
Invocation POST /agent/invoke {tool, args} — the shared tool registry runs the action.
Same registry English typing, chip taps, and slash commands (future) all end up here — one code path.
Voice Browser SpeechRecognition API. Free, no external service. Falls back gracefully.
Mentions GET /agent/entities?type=student&q=… — typeahead over students, staff, classes. Chip resolves to a stable ID.
Streaming POST /agent/stream {tool,args} — Server-Sent Events with named events (step, tool_call, tool_result, token, message_end). Per-turn connection — closes as soon as the turn is done.
